# Traits Note Rules

What the notes in `traits` look like. The whole-SRD rules are in the [README](../README.md#note-rules); Sweep and the "Check notes" workflow check both.

## trait

| Key          | Required | Values   |
| ------------ | -------- | -------- |
| `srd-type`   | yes      | `trait`  |
| `section`    | yes      | `Traits` |
| `trait-type` | yes      | `text`   |

Headings, in order:

1. `# (name)`
