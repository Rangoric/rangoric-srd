# Unseen but Not Undone

**Category**: [[rangoric-srd/traits/Character Traits#Magic Traits|magic trait]].

Without a single gesture, you can unleash a bloodline spell. Once per day, you can cast a [[rangoric-srd/classes/Sorcerer#^sorcerer-bloodline|bloodline]] spell as if you had the [[rangoric-srd/feats/Still Spell|Still Spell]] feat. Using this trait does not modify the spell's level.
