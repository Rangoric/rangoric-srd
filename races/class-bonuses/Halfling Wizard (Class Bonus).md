# Halfling Wizard

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Wizard#^wizard-class-bonuses|wizard]] level._

Add +1/2 to the wizard's effective class level for the purposes of determining his [[rangoric-srd/classes/Wizard#^familiar-basics|familiar]]'s natural armor adjustment, Intelligence, and special abilities.
