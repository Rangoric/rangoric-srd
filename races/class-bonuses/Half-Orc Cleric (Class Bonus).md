# Half-Orc Cleric

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Cleric#^cleric-class-bonuses|cleric]] level._

Select one [[rangoric-srd/classes/Cleric#^cleric-domains|domain power]] granted at 1st level that is normally usable a number of times per day equal to 3 + the cleric's Wisdom modifier. The cleric adds +1/2 to the number of uses per day of that domain power.
