# Half-Elf Ranger

*A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Ranger#^ranger-class-bonuses|ranger]] level.*

Add +1 skill rank to the ranger's [[rangoric-srd/classes/Ranger#^ranger-animal-companion|animal companion]]. If the ranger ever replaces his companion, the new companion gains these bonus skill ranks.
