# Halfling Bard

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Bard#^bard-class-bonuses|bard]] level._

Add +1/2 on [[rangoric-srd/skills/Deception|Deception]] checks to pass secret messages, +1/2 on [[rangoric-srd/skills/Persuasion|Persuasion]] checks to gather information, and +1/2 on [[rangoric-srd/skills/Imitation|Imitation]] checks to appear as an elven, half-elven, or human child.
