# Halfling Skald

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Skald#^skald-class-bonuses|skald]] level._

Choose a weapon from the following list: [[rangoric-srd/equipment/weapons/Dagger|dagger]], [[rangoric-srd/equipment/weapons/Sling|sling]], or any weapon with the word "halfling" in its name. Add a +1/2 bonus on critical hit confirmation rolls with that weapon (maximum bonus +4). This bonus doesn't stack with those gained through [[rangoric-srd/feats/Critical Focus|Critical Focus]] and similar effects.
