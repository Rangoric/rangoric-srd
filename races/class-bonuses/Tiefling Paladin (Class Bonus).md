# Tiefling Paladin

_A [[rangoric-srd/races/Tiefling|tiefling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Paladin#^paladin-class-bonuses|paladin]] level._

Add +1 to the amount of damage the paladin heals with [[rangoric-srd/classes/Paladin#^paladin-lay-on-hands|lay on hands]], but only when the paladin uses that ability on herself.
