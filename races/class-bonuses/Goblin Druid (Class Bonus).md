# Goblin Druid

_A [[rangoric-srd/races/Goblin|goblin]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Druid#^druid-class-bonuses|druid]] level._

Add +1 hit points to the druid's [[rangoric-srd/classes/Druid#^druid-animal-companion|animal companion]]. If the druid ever replaces her animal companion, the new animal companion gains these bonus hit points.
