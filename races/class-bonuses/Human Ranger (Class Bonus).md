# Human Ranger

_A [[rangoric-srd/races/Human|human]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Ranger#^ranger-class-bonuses|ranger]] level._

Add +1 hit point or +1 skill rank to the ranger's [[rangoric-srd/classes/Ranger#^ranger-animal-companion|animal companion]]. If the ranger ever replaces his companion, the new companion gains these bonus hit points or skill ranks.
