# Half-Elf Arcanist

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Arcanist#^arcanist-class-bonuses|arcanist]] level._

When casting arcanist [[rangoric-srd/spells/Schools of Magic#Enchantment|enchantment]] spells, add 1/3 to the effective caster level, but only for the purpose of determining duration.
