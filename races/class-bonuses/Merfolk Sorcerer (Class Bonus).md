# Merfolk Sorcerer

_A [[rangoric-srd/races/Merfolk|merfolk]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Sorcerer#^sorcerer-class-bonuses|sorcerer]] level._

Add +1/2 to the sorcerer's caster level when determining the range of any spells with the water descriptor.
