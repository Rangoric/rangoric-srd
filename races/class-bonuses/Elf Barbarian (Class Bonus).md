# Elf Barbarian

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Barbarian#^barbarian-class-bonuses|barbarian]] level._

Add +1 to the barbarian's base speed. In combat this option has no effect unless the barbarian has five barbarian levels (or another increment of five). This bonus stacks with the barbarian's [[rangoric-srd/classes/Barbarian#^barbarian-fast-movement|fast movement]] feature and applies under the same conditions as that feature.
