# Half-Elf Hunter

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Hunter#^hunter-class-bonuses|hunter]] level._

Add 1 foot to the hunter's [[rangoric-srd/classes/Hunter#^hunter-animal-companion|companion]]'s base speed. In combat, this has an effect only for every five increases in base speed.
