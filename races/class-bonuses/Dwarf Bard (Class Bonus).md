# Dwarf Bard

_A [[rangoric-srd/races/Dwarf|dwarf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Bard#^bard-class-bonuses|bard]] level._

Reduce [[rangoric-srd/equipment/Equipment Armor#^arcane-spell-failure|arcane spell failure]] chance for casting bard spells when wearing medium armor by +1%. Once the total reaches 10%, the bard also receives [[rangoric-srd/feats/Armor Proficiency (Medium)|Armor Proficiency (Medium)]], if he does not already possess it.
