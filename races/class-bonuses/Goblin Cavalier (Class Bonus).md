# Goblin Cavalier

_A [[rangoric-srd/races/Goblin|goblin]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Cavalier#^cavalier-class-bonuses|cavalier]] level._

Add +1 hit points to the cavalier's [[rangoric-srd/classes/Cavalier#^cavalier-mount|mount]] companion. If the cavalier ever replaces his mount, the new mount gains these bonus hit points.
