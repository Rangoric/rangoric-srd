# Elf Cavalier

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Cavalier#^cavalier-class-bonuses|cavalier]] level._

Add +1 hit point to the cavalier's [[rangoric-srd/classes/Cavalier#^cavalier-mount|mount]]. If the cavalier ever replaces his mount, the new mount gains these bonus hit points.
