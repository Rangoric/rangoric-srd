# Elf Rogue

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Rogue#^rogue-class-bonuses|rogue]] level._

Add +1 to the number of times per day the rogue can cast a cantrip or 1st-level spell gained from the [[rangoric-srd/class-options/rogue-talents/Minor Magic (Rogue Talent)|minor magic]] or [[rangoric-srd/class-options/rogue-talents/Major Magic (Rogue Talent)|major magic]] [[rangoric-srd/classes/Rogue#^rogue-talents|talent]]. The number of times this bonus is chosen for the major magic talent cannot exceed the number of times it is chosen for the minor magic talent. The rogue must possess the associated rogue talent to choose these options.
