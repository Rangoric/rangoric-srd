# Oread Monk

_An [[rangoric-srd/races/Oread|oread]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Monk#^monk-class-bonuses|monk]] or [[rangoric-srd/classes/Unchained Monk#^unchained-monk-class-bonuses|unchained monk]] level._

Add +1/3 on critical hit confirmation rolls made with [[rangoric-srd/classes/Monk#^unarmed-strike|unarmed strikes]] (maximum bonus of +5). This bonus does not stack with [[rangoric-srd/feats/Critical Focus|Critical Focus]].
