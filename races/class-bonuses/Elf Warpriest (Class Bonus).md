# Elf Warpriest

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Warpriest#^warpriest-class-bonuses|warpriest]] level._

Add 1/2 to the number of times per day the warpriest can use [[rangoric-srd/classes/Warpriest#^warpriest-blessings|blessings]], but he can use these additional blessings on only those from the [[rangoric-srd/class-options/blessings/Air (Blessing)|Air]], [[rangoric-srd/class-options/blessings/Animal (Blessing)|Animal]], [[rangoric-srd/class-options/blessings/Charm (Blessing)|Charm]], [[rangoric-srd/class-options/blessings/Magic (Blessing)|Magic]], [[rangoric-srd/class-options/blessings/Plant (Blessing)|Plant]], or [[rangoric-srd/class-options/blessings/Sun (Blessing)|Sun]] domains.
