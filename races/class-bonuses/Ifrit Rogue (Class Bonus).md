# Ifrit Rogue

*An [[rangoric-srd/races/Ifrit|ifrit]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Rogue#^rogue-class-bonuses|rogue]] level.*

Add a +1/2 bonus on [[rangoric-srd/skills/Athletics|Athletics]] checks to [[rangoric-srd/skills/Athletics#Jumping|jump]] and a +1/2 bonus on [[rangoric-srd/skills/Intimidation|Intimidation]] checks to demoralize enemies.
