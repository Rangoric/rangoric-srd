# Orc Fighter

_An [[rangoric-srd/races/Orc|orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Fighter#^fighter-class-bonuses|fighter]] level._

Add +2 to the fighter's Constitution score for the purpose of determining when he [[rangoric-srd/combat/Injury and Death#^death|dies]] from negative hit points.
