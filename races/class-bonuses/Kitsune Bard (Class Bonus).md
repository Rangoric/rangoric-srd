# Kitsune Bard

_A [[rangoric-srd/races/Kitsune|kitsune]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Bard#^bard-class-bonuses|bard]] level._

Add a +1/2 bonus on [[rangoric-srd/skills/Deception|Deception]] checks to lie and a +1/2 bonus on [[rangoric-srd/skills/Persuasion|Persuasion]] checks to [[rangoric-srd/skills/Persuasion#Gathering Information|gather information]].
