# Half-Elf Warpriest

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Warpriest#^warpriest-class-bonuses|warpriest]] level._

Gain a +1/3 bonus on the damage dealt or healed with the warpriest's [[rangoric-srd/classes/Warpriest#^warpriest-channel-energy|channel energy]] ability.
