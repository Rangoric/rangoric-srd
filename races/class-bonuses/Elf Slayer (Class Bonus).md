# Elf Slayer

*An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Slayer#^slayer-class-bonuses|slayer]] level.*

Increase the [[rangoric-srd/classes/Slayer#^slayer-studied-target|studied target]] bonus on [[rangoric-srd/skills/Perception|Perception]] and [[rangoric-srd/skills/Fieldcraft|Fieldcraft]] checks by 1/4. When the slayer gains the [[rangoric-srd/classes/Slayer#^slayer-stalker|stalker]] class feature, he also gains this increase to the studied target bonus on [[rangoric-srd/skills/Stealth|Stealth]] checks.
