# Half-Orc Wizard

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Wizard#^wizard-class-bonuses|wizard]] level._

Add a +1 bonus on [[rangoric-srd/rules/Concentration (Check)|concentration checks]] made due to taking damage while casting wizard spells.
