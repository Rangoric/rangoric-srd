# Half-Orc Swashbuckler

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Swashbuckler#^swashbuckler-class-bonuses|swashbuckler]] level._

Gain a +1/3 bonus on all critical hit confirmation rolls made while using the [[rangoric-srd/class-options/deeds/Precise Strike (Deed)|precise strike]] [[rangoric-srd/classes/Swashbuckler#^swashbuckler-deeds|deed]] (maximum bonus of +5). This bonus doesn't stack with those gained through [[rangoric-srd/feats/Critical Focus|Critical Focus]] and similar effects.
