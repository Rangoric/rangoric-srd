# Orc Cavalier

_An [[rangoric-srd/races/Orc|orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Cavalier#^cavalier-class-bonuses|cavalier]] level._

Add +1 to the cavalier's [[rangoric-srd/combat/Combat Maneuvers#Combat Maneuver Bonus|CMB]] when making [[rangoric-srd/combat/Combat Maneuvers#Bull Rush|bull rush]] or [[rangoric-srd/combat/Combat Maneuvers#Overrun|overrun]] combat maneuvers against a [[rangoric-srd/classes/Cavalier#^cavalier-challenge|challenged]] target.
