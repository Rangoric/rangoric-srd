# Halfling Cavalier

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Cavalier#^cavalier-class-bonuses|cavalier]] level._

Add +1/2 to the cavalier's effective class level for the purposes of determining the damage he deals when making an attack of opportunity against a [[rangoric-srd/classes/Cavalier#^cavalier-challenge|challenged]] foe.
