# Dwarf Gunslinger

*A [[rangoric-srd/races/Dwarf|dwarf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Gunslinger#^gunslinger-class-bonuses|gunslinger]] level.*

Reduce the [[rangoric-srd/equipment/Firearms#Misfires|misfire]] chance for one type of firearm by 1/4. You cannot reduce the misfire chance of a firearm below 1.
