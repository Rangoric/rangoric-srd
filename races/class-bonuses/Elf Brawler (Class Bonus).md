# Elf Brawler

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Brawler#^brawler-class-bonuses|brawler]] level._

Add 1 foot to the brawler's base speed. In combat, this has an effect only for every five increases in the brawler's base speed.
