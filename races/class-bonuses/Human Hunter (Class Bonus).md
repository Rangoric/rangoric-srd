# Human Hunter

_A [[rangoric-srd/races/Human|human]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Hunter#^hunter-class-bonuses|hunter]] level._

Add 1 skill rank to the hunter's [[rangoric-srd/classes/Hunter#^hunter-animal-companion|animal companion]]. If the hunter replaces his animal companion, the new animal companion gains these bonus skill ranks.
