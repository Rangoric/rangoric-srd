# Halfling Bloodrager

*A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Bloodrager#^bloodrager-class-bonuses|bloodrager]] level.*

Gain a +1/4 dodge bonus to AC while [[rangoric-srd/classes/Bloodrager#^bloodrager-bloodrage|bloodraging]] against creatures at least one size category larger than the bloodrager.
