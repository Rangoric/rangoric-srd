# Elf Shaman

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Shaman#^shaman-class-bonuses|shaman]] level._

Add 5 feet to the range of a chosen [[rangoric-srd/classes/Shaman#^shaman-hex|shaman hex]]. Multiple bonuses from this ability can apply to the same hex, to a maximum of an additional 30 feet for any single hex.
