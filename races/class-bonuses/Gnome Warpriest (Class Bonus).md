# Gnome Warpriest

_A [[rangoric-srd/races/Gnome|gnome]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Warpriest#^warpriest-class-bonuses|warpriest]] level._

Add 1/2 to the result of the warpriest's [[rangoric-srd/classes/Warpriest#^warpriest-channel-energy|channeled energy]] when healing creatures of the animal, fey, and plant types.
