# Halfling Brawler

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Brawler#^brawler-class-bonuses|brawler]] level._

Gain a +1 bonus to the brawler's [[rangoric-srd/combat/Combat Maneuvers#Combat Maneuver Defense|CMD]] when resisting a [[rangoric-srd/combat/Combat Maneuvers#Grapple|grapple]] or [[rangoric-srd/combat/Combat Maneuvers#Overrun|overrun]] combat maneuver.
