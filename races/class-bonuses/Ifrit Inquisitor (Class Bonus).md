# Ifrit Inquisitor

_An [[rangoric-srd/races/Ifrit|ifrit]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Inquisitor (Class)#^inquisitor-class-bonuses|inquisitor]] level._

Add a +1/2 bonus on [[rangoric-srd/skills/Intimidation|Intimidation]] checks made against creatures with the fire subtype and a +1/2 bonus on [[rangoric-srd/skills/Theology|Theology]] checks relating to the Plane of Fire.
