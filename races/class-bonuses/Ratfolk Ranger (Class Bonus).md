# Ratfolk Ranger

_A [[rangoric-srd/races/Ratfolk|ratfolk]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Ranger#^ranger-class-bonuses|ranger]] level._

Add +1 to an [[rangoric-srd/classes/Ranger#^ranger-animal-companion|animal companion]]'s [[rangoric-srd/combat/Combat Maneuvers#Combat Maneuver Defense|CMD]] when adjacent to the ranger. If the ranger ever replaces his animal companion, the new animal companion gains this bonus.
