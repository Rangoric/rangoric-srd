# Half-Elf Fighter

*A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Fighter#^fighter-class-bonuses|fighter]] level.*

Add +1 to the fighter's [[rangoric-srd/combat/Combat Maneuvers#Combat Maneuver Defense|CMD]] when resisting a [[rangoric-srd/combat/Combat Maneuvers#Disarm|disarm]] or [[rangoric-srd/combat/Combat Maneuvers#Overrun|overrun]] combat maneuver.
