# Halfling Shaman

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Shaman#^shaman-class-bonuses|shaman]] level._

Add 1/2 to the shaman's effective class level for the purpose of determining her [[rangoric-srd/classes/Shaman#^shaman-spirit-animal|spirit animal]]'s natural armor adjustment, Intelligence, and special abilities.
