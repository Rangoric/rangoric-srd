# Catfolk Oracle

_A [[rangoric-srd/races/Catfolk|catfolk]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Oracle#^oracle-class-bonuses|oracle]] level._

Add one [[rangoric-srd/classes/Oracle#^oracle-spells|spell known]] from the [[rangoric-srd/spells/Cleric Spell List|oracle spell list]]. This spell must be at least one level below the highest spell level the oracle can cast.
