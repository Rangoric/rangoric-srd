# Ratfolk Monk

_A [[rangoric-srd/races/Ratfolk|ratfolk]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Monk#^monk-class-bonuses|monk]] or [[rangoric-srd/classes/Unchained Monk#^unchained-monk-class-bonuses|unchained monk]] level._

Add +1 foot to the speed the monk can move while making a [[rangoric-srd/skills/Stealth|Stealth]] check without taking a penalty. This has no effect unless the monk has five monk levels (or another increment of five). This does not allow the monk to use Stealth while running or charging.
