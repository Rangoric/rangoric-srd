# Half-Elf Paladin

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Paladin#^paladin-class-bonuses|paladin]] level._

Add +1 foot to the size of all the paladin's aura class features. This option has no effect unless the paladin has five paladin levels (or another increment of 5); an aura of 14 feet is effectively the same as a 10-foot aura, for example.
