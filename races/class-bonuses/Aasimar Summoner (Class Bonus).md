# Aasimar Summoner

_An [[rangoric-srd/races/Aasimar|aasimar]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Summoner#^summoner-class-bonuses|summoner]] or [[rangoric-srd/classes/Unchained Summoner#^unchained-summoner-class-bonuses|unchained summoner]] level._

Add [[rangoric-srd/rules/Special Abilities and Conditions#Damage Reduction|DR]] 1/evil to the summoner's [[rangoric-srd/classes/Summoner#^summoner-eidolon|eidolon]]. For each summoner level after the first, the DR/evil increases by +1/2 (maximum DR 10/evil).
