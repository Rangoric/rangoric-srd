# Svirfneblin Alchemist

_A [[rangoric-srd/races/Svirfneblin|svirfneblin]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Alchemist#^alchemist-class-bonuses|alchemist]] level._

Add one extract formula from the alchemist's list to the alchemist's [[rangoric-srd/classes/Alchemist#^alchemist-formulae|formula book]]. This formula must be at least one level below the highest formula level the alchemist can create.
