# Catfolk Sorcerer

_A [[rangoric-srd/races/Catfolk|catfolk]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Sorcerer#^sorcerer-class-bonuses|sorcerer]] level._

Select one [[rangoric-srd/classes/Sorcerer#^sorcerer-bloodline|bloodline power]] at 1st level that is normally usable a number of times equal to 3 + the sorcerer's Charisma modifier. The sorcerer adds +1/2 to the number of uses per day of that bloodline power.
