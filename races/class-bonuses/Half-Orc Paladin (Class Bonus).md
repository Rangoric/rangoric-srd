# Half-Orc Paladin

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Paladin#^paladin-class-bonuses|paladin]] level._

Add +1/3 on critical hit confirmation rolls made while using [[rangoric-srd/classes/Paladin#^paladin-smite-evil|smite evil]] (maximum bonus of +5). This bonus does not stack with [[rangoric-srd/feats/Critical Focus|Critical Focus]].
