# Goblin Barbarian

_A [[rangoric-srd/races/Goblin|goblin]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Barbarian#^barbarian-class-bonuses|barbarian]] level._

Add +1/2 on critical hit confirmation rolls for attacks made with unarmed strikes or natural weapons (maximum bonus of +4). This bonus does not stack with [[rangoric-srd/feats/Critical Focus|Critical Focus]].
