# Half-Orc Slayer

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Slayer#^slayer-class-bonuses|slayer]] level._

Gain a +1/3 bonus on critical hit confirmation rolls made while using [[rangoric-srd/classes/Slayer#^slayer-sneak-attack|sneak attack]] (maximum bonus of +5). This bonus doesn't stack with those gained through [[rangoric-srd/feats/Critical Focus|Critical Focus]] and similar effects.
