# Dwarf Monk

_A [[rangoric-srd/races/Dwarf|dwarf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Monk#^monk-class-bonuses|monk]] or [[rangoric-srd/classes/Unchained Monk#^unchained-monk-class-bonuses|unchained monk]] level._

Reduce the Hardness of any object made of clay, stone, or metal by 1 whenever the object is struck by the monk's [[rangoric-srd/classes/Monk#^unarmed-strike|unarmed strike]] (minimum of 0).
