# Dwarf Brawler

_A [[rangoric-srd/races/Dwarf|dwarf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Brawler#^brawler-class-bonuses|brawler]] level._

Reduce the hardness of any object made from clay, stone, or metal by 1 whenever the object is struck by the brawler's [[rangoric-srd/classes/Brawler#^brawler-unarmed-strike|unarmed strike]] (minimum 0).
