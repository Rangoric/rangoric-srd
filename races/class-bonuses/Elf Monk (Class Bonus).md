# Elf Monk

*An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Monk#^monk-class-bonuses|monk]] or [[rangoric-srd/classes/Unchained Monk#^unchained-monk-class-bonuses|unchained monk]] level.*

Add +1 to the monk's base speed. In combat this option has no effect unless the monk has five monk levels (or another increment of five). This bonus stacks with the monk's [[rangoric-srd/classes/Monk#^monk-fast-movement|fast movement]] class feature and applies under the same conditions as that feature.
