# Half-Elf Wizard

*A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Wizard#^wizard-class-bonuses|wizard]] level.*

When casting wizard [[rangoric-srd/spells/Schools of Magic#Enchantment|enchantment]] spells, add +1/3 to the effective caster level of the spell, but only to determine the spell's duration.
