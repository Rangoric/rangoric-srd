# Half-Elf Rogue

Add a +1/2 bonus on [[rangoric-srd/skills/Deception|Deception]] checks to [[rangoric-srd/combat/Combat Special Attacks#Feint|feint]] and [[rangoric-srd/skills/Persuasion|Persuasion]] checks to [[rangoric-srd/skills/Persuasion#Gathering Information|gather information]].
