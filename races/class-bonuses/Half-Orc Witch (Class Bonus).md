# Half-Orc Witch

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Witch#^witch-class-bonuses|witch]] level._

Add +1 skill rank to the witch's [[rangoric-srd/classes/Witch#^witch-familiar|familiar]]. If the half-orc ever replaces her familiar, the new familiar gains these bonus skill ranks.
