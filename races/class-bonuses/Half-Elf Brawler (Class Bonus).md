# Half-Elf Brawler

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Brawler#^brawler-class-bonuses|brawler]] level._

Add 1 to the brawler's [[rangoric-srd/combat/Combat Maneuvers#Combat Maneuver Defense|CMD]] when she's resisting a [[rangoric-srd/combat/Combat Maneuvers#Trip|trip]] or [[rangoric-srd/combat/Combat Maneuvers#Overrun|overrun]] combat maneuver.
