# Sylph Witch

_A [[rangoric-srd/races/Sylph|sylph]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Witch#^witch-class-bonuses|witch]] level._

Add a +1/2 bonus on [[rangoric-srd/skills/Stealth|Stealth]] checks and [[rangoric-srd/skills/Perception|Perception]] checks made by the witch's [[rangoric-srd/classes/Witch#^witch-familiar|familiar]]. If the sylph ever replaces her familiar, the new familiar gains these bonus skill ranks.
