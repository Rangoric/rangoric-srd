# Half-Elf Druid

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Druid#^druid-class-bonuses|druid]] level._

Select one [[rangoric-srd/classes/Cleric#^cleric-domains|cleric domain power]] at 1st level that is normally usable a number of times per day equal to 3 + the druid's Wisdom modifier. The druid adds +1/2 to the number of uses per day of that domain power. For druids whose [[rangoric-srd/classes/Druid#^druid-nature-bond|nature bond]] gives them an [[rangoric-srd/classes/Druid#^druid-animal-companion|animal companion]], add +1 skill rank to the animal companion. If the druid ever replaces her animal companion, the new companion gains these bonus skill ranks.
