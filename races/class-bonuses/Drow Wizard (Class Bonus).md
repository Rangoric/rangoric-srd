# Drow Wizard

_A [[rangoric-srd/races/Drow|drow]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Wizard#^wizard-class-bonuses|wizard]] level._

Select one [[rangoric-srd/classes/Wizard#^wizard-arcane-school|arcane school power]] at 1st level that is normally usable a number of times per day equal to 3 + the wizard's Intelligence modifier. The wizard adds +1/2 to the number of uses per day of that arcane school power.
