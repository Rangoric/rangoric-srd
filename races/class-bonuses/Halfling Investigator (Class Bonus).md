# Halfling Investigator

_A [[rangoric-srd/races/Halfling|halfling]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Investigator#^investigator-class-bonuses|investigator]] level._

Add one extract formula from the investigator's list to his [[rangoric-srd/classes/Investigator#^investigator-alchemy|formula book]]. This formula must be at least 1 formula level below the highest level the investigator can create.
