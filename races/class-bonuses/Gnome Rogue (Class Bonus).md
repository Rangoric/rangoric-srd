# Gnome Rogue

_A [[rangoric-srd/races/Gnome|gnome]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Rogue#^rogue-class-bonuses|rogue]] level._

The rogue gains a +1/2 bonus on [[rangoric-srd/skills/Engineering|Engineering]] and [[rangoric-srd/skills/Emulation|Emulation]] checks related to glyphs, symbols, scrolls, and other magical writings.
