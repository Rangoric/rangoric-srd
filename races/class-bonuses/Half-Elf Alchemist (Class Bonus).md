# Half-Elf Alchemist

_A [[rangoric-srd/races/Half-Elf|half-elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Alchemist#^alchemist-class-bonuses|alchemist]] level._

Add +1 foot to the range increment of the alchemist's [[rangoric-srd/combat/Combat Special Attacks#Throw Splash Weapon|thrown splash weapons]] (including the alchemist's [[rangoric-srd/classes/Alchemist#^alchemist-bomb|bombs]]). This option has no effect unless the alchemist has five alchemist levels (or another increment of 5); a range increment of 24 feet is effectively the same as a range increment of 20 feet, for example.
