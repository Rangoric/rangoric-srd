# Elf Bard

*An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Bard#^bard-class-bonuses|bard]] level.*

Add +1 to the bard's [[rangoric-srd/combat/Combat Maneuvers#Combat Maneuver Defense|CMD]] when resisting a [[rangoric-srd/combat/Combat Maneuvers#Disarm|disarm]] or [[rangoric-srd/combat/Combat Maneuvers#Sunder|sunder]] attempt.
