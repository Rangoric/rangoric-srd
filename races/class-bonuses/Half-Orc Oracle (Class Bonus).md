# Half-Orc Oracle

_A [[rangoric-srd/races/Half-Orc|half-orc]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Oracle#^oracle-class-bonuses|oracle]] level._

Add one [[rangoric-srd/classes/Oracle#^oracle-spells|spell known]] from the oracle spell list. This spell must be at least one level below the highest spell level the oracle can cast.
