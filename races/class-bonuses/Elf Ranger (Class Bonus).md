# Elf Ranger

_An [[rangoric-srd/races/Elf|elf]] [[rangoric-srd/races/PC Races#^class-bonuses|class bonus]], gained for each [[rangoric-srd/classes/Ranger#^ranger-class-bonuses|ranger]] level._

Choose a weapon from the following list: longbow, longsword, rapier, shortbow, short sword, or any weapon with "elven" in its name. Add +1/2 on critical hit confirmation rolls made while using that weapon (maximum bonus of +4). This bonus does not stack with [[rangoric-srd/feats/Critical Focus|Critical Focus]].
