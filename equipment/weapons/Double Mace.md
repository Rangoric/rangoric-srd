# Double Mace

*Exotic two-handed melee weapon (double).* Cost 70 gp; Dmg 1d6/1d6 (S), 1d8/1d8 (M); Critical x2; Weight 22 lb.; Type Bludgeoning. ^stats

A double mace is a large double weapon. When used as if fighting with two weapons, it incurs all the normal attack penalties associated with two weapon fighting as if it were a one-handed weapon and a light weapon. A creature using a double weapon in one hand cannot use it as a double weapon.
