# Double Hammer

*Martial two-handed melee weapon (double).* Cost 150 gp; Dmg 1d6/1d6 (S), 1d8/1d8 (M); Critical x3; Weight 35 lb.; Type Bludgeoning. ^stats

As with other double weapons, the double hammer allows you to fight with it as if fighting with two weapons. If you do, you incur all of the normal attack penalties associated with fighting with two weapons, as if you were using a one-handed weapon and a light weapon. A creature using a double weapon in one hand, such as an ogre using a double hammer, cannot use it as a double weapon.
