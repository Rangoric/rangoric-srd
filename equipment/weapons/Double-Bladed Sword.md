# Double-Bladed Sword

*Exotic two-handed melee weapon.* Cost 60 gp; Dmg 1d8 (S), 1d10 (M); Critical 19-20/x2; Weight 8 lb.; Type Slashing. ^stats

The double-bladed sword resembles a longsword, save that it has two blades mounted parallel to each other, and a lengthened hilt. A double-bladed sword is too awkward to use in one hand without special training, making it an exotic weapon. A Medium sized character can use a double-bladed sword two-handed as a martial weapon, or a Large creature can use it one-handed in the same way.
