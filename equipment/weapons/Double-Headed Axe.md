# Double-Headed Axe

*Exotic two-handed melee weapon.* Cost 40 gp; Dmg 1d8 (S), 1d10 (M); Critical x3; Weight 15 lb.; Type Slashing. ^stats

This unusual battleaxe has two axe-heads, both oriented in the same direction so that both heads hit with a single strike. A double-headed axe is too awkward to use in one hand without special training; thus it is an exotic weapon. A Medium-size character can use a double-headed axe two-handed as a martial weapon, and a Large creature can use it one-handed in the same way.
