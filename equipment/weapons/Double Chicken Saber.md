# Double Chicken Saber

_Martial one-handed melee weapon (disarm, monk)._ Cost 12 gp; Dmg 1d4 (S), 1d6 (M); Critical 19–20/x2; Weight 3 lb.; Type Slashing. ^stats

The tip of this 3-foot-long, straight-bladed sword is bent into two staggered, opposing sharpened spurs that can be used to pull weapons from an opponent's hands.

A double chicken saber is a [[rangoric-srd/equipment/Equipment Weapons#^weapon-disarm|disarm]] weapon. A double chicken saber is a special [[rangoric-srd/classes/Monk|monk]] weapon.
