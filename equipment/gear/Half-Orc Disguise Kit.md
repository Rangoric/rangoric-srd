# Half-Orc Disguise Kit

This specifically designed kit was put together by half-orcs to help them appear more human. It includes skin cream to disguise green-gray skin color and other items designed to conceal or draw attention away from typical half-orc physical characteristics. Using this kit on a half-orc grants a +3 bonus on [[rangoric-srd/skills/Imitation|Imitation]] checks to appear human. Used on an orc, it only grants a +1 bonus on these checks.

Price 75 gp; Weight 1 lb.
