# Tea Ceremony Set

This includes a tray, a teapot, a whisk, a bowl to mix the tea in, four tiny cups, and a decorative box in which to store all of these items. The ceremonial brewing of tea is part of the classical tea ceremony. Knowing the proper steps for preparing and participating in a tea ceremony requires a successful DC 15 [[rangoric-srd/skills/Society|Society]] check.

Price 25 gp; Weight 5 lb.
