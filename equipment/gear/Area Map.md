# Area Map

A geographically relevant map grants a user a +1 circumstance bonus on [[rangoric-srd/skills/Fieldcraft|Fieldcraft]] checks made to navigate in the wilderness. It also can be used to grant the same bonus on [[rangoric-srd/skills/Dungeoneering|Dungeoneering]] checks made to navigate underground.

Price 50 gp; Weight 2 lb.
