# Riding Gecko, Combat Trained (Mount)

Larger than even giant geckos, these mammoth lizards have been specifically bred to be used as mounts. Prized for their ability to run along cave ceilings and sheer walls, they require [[rangoric-srd/equipment/gear/Saddle, Exotic Riding|exotic saddles]] to ride. A riding gecko has the same statistics as a [[rangoric-srd/monsters/Giant Gecko|giant gecko]] with the giant template.

This animal is sold combat trained.

Price 400 gp; Weight 1,500 lb.
