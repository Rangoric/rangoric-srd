# Raktavarna Rakshasa Venom

A poison; how afflictions work, and what each line means, is in [[rangoric-srd/rules/Afflictions#The Affliction Block|afflictions]]. It is the venom of the [[rangoric-srd/monsters/rakshasas/Raktavarna|raktavarna]]. Each time a victim takes Wisdom damage from this poison, a _[[rangoric-srd/spells/Modify Memory|modify memory]]_ effect causes the victim to forget the previous minute's interactions with the raktavarna, as long as the raktavarna is no longer visible or is in object form. The attack bonus is Constitution-based.

- **Type**: poison, injury
- **Attack**: +3 vs Fortitude
- **Frequency**: 1/round for 6 rounds
- **Effect**: 1d2 Wisdom damage plus modify memory
- **Cure**: 1 miss
