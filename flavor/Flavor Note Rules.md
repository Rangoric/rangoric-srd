# Flavor Note Rules

What the notes in `flavor` look like. The whole-SRD rules are in the [README](../README.md#note-rules); Sweep and the "Check notes" workflow check both.

## flavor

| Key          | Required | Values           |
| ------------ | -------- | ---------------- |
| `srd-type`   | yes      | `flavor`         |
| `page`       | no       | `number`         |
| `place-kind` | no       | `site`, `region` |
| `region`     | no       | `text`           |
