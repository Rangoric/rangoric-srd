# Shadow Evocation, Greater

*Illusion (Shadow)*

  - **Level**: Sor/Wiz 8

This spell functions like [[rangoric-srd/spells/Shadow Evocation|shadow evocation]], except that it enables you to create partially real, illusory versions of sorcerer or wizard evocation spells of 7th level or lower. If recognized as a greater shadow evocation, a damaging spell deals only three-fifths (60%) damage.
