# False Resurrection, Greater

*Conjuration (Calling) \[Evil, Lawful, Ruse\]*

  - **Level**: Clr 9
  - **Components**: V, S, M, DF (diamond worth 25,000 gp)
  - **Casting Time**: 1 minute
  - **Range**: Touch
  - **Target**: Dead creature touched
  - **Duration**: Permanent
  - **Spell Resistance**: Yes

This spell functions as [[rangoric-srd/spells/False Resurrection|false resurrection]] except that it calls a belier devil with the young simple template to possess the body and all parts of *[[rangoric-srd/spells/False Resurrection|false resurrection]]* that function like *[[rangoric-srd/spells/Resurrection|resurrection]]* instead function like true *[[rangoric-srd/spells/Resurrection|resurrection]]*. Attempts to identify greater *[[rangoric-srd/spells/False Resurrection|false resurrection]]* with a skill check incorrectly identify it as [[rangoric-srd/spells/True Resurrection|true resurrection]]. A fooled viewer mistakes greater *[[rangoric-srd/spells/False Resurrection|false resurrection]]*'s aura as the lingering aura of an instantaneous conjuration effect.
