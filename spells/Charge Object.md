# Charge Object

*Transmutation*

  - **Level**: Med 1, Mes 1, Occ 1, Psy 1, Spi 1
  - **Components**: V, S
  - **Casting Time**: 10 minutes
  - **Range**: Touch
  - **Target**: Object touched
  - **Duration**: Permanent
  - **Saving Throw**: None; see text
  - **Spell Resistance**: No

You charge an item with minor psychic energy. The item can be detected by the *[[rangoric-srd/spells/Detect Psychic Significance|detect psychic significance]]* spell. If you wish, you can imprint the item with your ownership history. Spells such as *[[rangoric-srd/spells/Object Reading (Spell)|object reading]]* and uses of the psychometry occult skill unlock can reveal any information about yourself you impart into the object, including your name, alignment, profession, and a summary of your experiences with the item. You can't impart false information into the object, but you can omit any details you'd prefer not to divulge. If the target object is already psychically charged, you can add more information to it, but you can't use *charge object* to erase existing psychic information.
