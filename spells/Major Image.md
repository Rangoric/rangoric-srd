# Major Image

*Illusion (Figment)*

  - **Level**: Brd 3, Skd 3, Sor/Wiz 3
  - **Duration**: Concentration + 3 rounds

This spell functions like [[rangoric-srd/spells/Silent Image|silent image]], except that sound, smell, and thermal illusions are included in the spell effect. While concentrating, you can move the image within the range.

The image disappears when struck by an opponent unless you cause the illusion to react appropriately.
