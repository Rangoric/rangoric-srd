# Id Insinuation III

_Enchantment (Compulsion) \[Mind-Affecting\]_

- **Level**: Psy 4
- **Components**: S
- **Casting Time**: 1 standard action
- **Range**: Close (25 ft. + 5 ft./2 levels)
- **Targets**: Three creatures
- **Duration**: Concentration + 1 round
- **Defense**: Will
- **Spell Resistance**: Yes

This functions as _[[rangoric-srd/spells/Id Insinuation I|id insinuation I]]_, except as noted above. In addition, on the first 2 rounds of the effect, the targets of this spell must roll twice to determine the result of their confused conditions. You select which roll is used. This spell can be [[rangoric-srd/spells/Magic Overview#^undercasting|undercast]].
