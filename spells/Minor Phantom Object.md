# Minor Phantom Object

_Illusion (Figment) \[Mind-Affecting\]_

- **Level**: Mes 4, Psy 4, Sor/Wiz 4
- **Components**: V, S
- **Casting Time**: 1 minute
- **Range**: 0 ft.
- **Effect**: Phantasmal, unattended, nonmagical object of nonliving plant matter, up to 1 cu. ft./level
- **Duration**: 10 minutes/level (D)
- **Defense**: Will
- **Spell Resistance**: Yes

This spell functions as the _minor creation spell_, except the object created is a semi-real phantasm. The object attacks the Will of any creature that interacts with it, and a miss causes the object to cease to exist. A gnome casting this spell may make a Mysticism check in place of any Craft check required to make a complex item.
