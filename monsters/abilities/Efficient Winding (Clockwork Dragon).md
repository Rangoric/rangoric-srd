# Efficient Winding (Clockwork Dragon)

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block_: “efficient winding”, on the Special Qualities line.

Built for long and dangerous missions, a clockwork dragon can function for 3 days per Hit Die each time it's wound. The [[rangoric-srd/monsters/clockwork/Clockwork Dragon|clockwork dragon]] has it.
