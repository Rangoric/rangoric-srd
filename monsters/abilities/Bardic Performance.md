# Bardic Performance

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Supernatural]] (Su). In a stat block_: “bardic performance”, on the Special Attacks line.

The creature may use bardic performance as a 4th-level bard (9 rounds/day), and can use countersong, distraction, fascinate, inspire competence, and inspire courage. Levels in the bard class stack with this ability. The [[rangoric-srd/monsters/Siren|siren]] has it.
