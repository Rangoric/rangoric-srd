# Efficient Winding (Clockwork Soldier)

*[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block*: “efficient winding”, on the Special Qualities line.

A clockwork soldier can function for 2 days per Hit Die every time it is wound. The [[rangoric-srd/monsters/clockwork/Clockwork Soldier|clockwork soldier]] has it.
