# Spore Cloud

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block_: “spore cloud”, on the Special Attacks line.

Once per day as a standard action, a myceloid can expel a 10-foot-radius burst of spores centered on itself. This cloud persists for 1d3 rounds. Any creature caught in this cloud or that moves through it is exposed to the myceloid's [[rangoric-srd/rules/afflictions/Purple Pox|purple pox]] disease—any one spore cloud attacks a creature only once, however, before the creature becomes permanently immune to that particular spore cloud's effects. The spore cloud does not hamper vision. The [[rangoric-srd/monsters/fungi/Myceloid|myceloid]] has it.
