# Dust Cloud

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block_: “dust cloud”, on the Special Attacks line.

A sabosan gains Hover as a bonus feat, and can use this feat to create a dust cloud even though it is not Large. The resulting dust cloud has only a 30-foot radius. The [[rangoric-srd/monsters/Sabosan|sabosan]] has it.
