# Item Use

*[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block*: “item use”, on the Special Qualities line.

A seugathi can utilize spell trigger devices as if it were a spellcaster of the appropriate class. As a free action by touch, it can identify all spell trigger properties an item has. Emulation is a class skill for seugathis. The [[rangoric-srd/monsters/Seugathi|seugathi]] has it.
