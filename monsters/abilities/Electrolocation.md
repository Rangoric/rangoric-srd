# Electrolocation

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block_: “electrolocation”, on the Special Qualities line.

While underwater, a creature with this ability can sense the tiny electrical currents that trigger muscle movement. This allows it to locate living prey and to distinguish it from inanimate objects. Treat electrolocation as [[rangoric-srd/monsters/abilities/Lifesense|lifesense]] with the listed range, but it functions only underwater. The [[rangoric-srd/monsters/Platypus|platypus]] has it.
