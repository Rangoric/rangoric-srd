# Coalesce Chaos

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Supernatural]] (Su). In a stat block_: “coalesce chaos”, on the Special Attacks line.

Once per day as a standard action, three or more naunets working together can create a roiling cloud of multicolored chaos matter. This effect is identical to solid fog (CL 12th) and lasts for 2d6 rounds. If six or more naunets are present, the coalesced chaos instead functions as acid fog (CL 12th). The [[rangoric-srd/monsters/proteans/Naunet|naunet]] has it.
