# Speak with Rats

_[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block_: “speak with rats”, on the Special Qualities line.

The creature can communicate with normal rats (including rat swarms and dire rats) as if using speak with animals. It can use Persuasion to alter a rat's attitude, and when so doing gains a +4 racial bonus on the check. Any ability that allows a creature to communicate with rats (such as speak with animals or a wererat's rat empathy) allows for communication with the creature. The [[rangoric-srd/monsters/Rat King|rat king]] has it.
