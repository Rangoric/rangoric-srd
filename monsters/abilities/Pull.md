# Pull

*[[rangoric-srd/monsters/Monster Types, Sybtypes, and Special Abilities#^special-abilities|Extraordinary]] (Ex). In a stat block*: “pull (tentacle, 5 feet)”, on the Special Attacks and Attack lines.

A creature with this ability can choose to make a free [[rangoric-srd/combat/Combat Maneuvers|combat maneuver check]] with a successful attack. If successful, this check pulls an opponent closer. The distance pulled is set by this ability. The type of attack that causes the pull and the distance pulled are included in the creature's entry. This ability only works on creatures of a size equal to or smaller than the pulling creature. Creatures pulled in this way do not provoke attacks of opportunity and stop if the pull would move them into a solid object or creature.
