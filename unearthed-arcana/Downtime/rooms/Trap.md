# Trap

- **Create**: see below
- **Benefit**: see below
- **Time**: see below
- **Size**: 1-4 squares

This can be a specific room in a building or an augmentation to another room. A Trap room might appear empty or it might be decorated to appear to be harmless in order to lure a target into the trap. A Trap costs are explained in the core rules, and building one uses the crafting rules in the core rules, though you may spend Goods and Labor toward this cost.
