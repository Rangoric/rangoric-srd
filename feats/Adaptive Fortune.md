# Adaptive Fortune

Your luck takes on almost legendary proportions.

**Prerequisites**: [[rangoric-srd/feats/Fortunate One|Fortunate One]], [[rangoric-srd/races/racial-traits/Adaptable Luck|adaptable luck]] racial trait, character level 10th, [[rangoric-srd/races/Halfling|halfling]].

**Benefit**: Increase the number of times per day you can use the [[rangoric-srd/races/racial-traits/Adaptable Luck|adaptable luck]] racial trait by 1. Furthermore, when you use adaptable luck, increase the luck bonus for each type of use by 2.
