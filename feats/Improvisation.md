# Improvisation

You can figure out how to do almost anything.

**Prerequisites**: Int 13, [[rangoric-srd/races/Human|human]].

**Benefit**: You gain a +2 bonus on all skill checks for skills you have no ranks in. Furthermore, you can use all [[rangoric-srd/skills/Skills Overview#Untrained Skill Checks|trained-only]] skills untrained.
