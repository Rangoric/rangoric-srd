# Psychic Maestro

You can use two occult skill unlocks more often.

**Prerequisites**: [[rangoric-srd/feats/Psychic Sensitivity|Psychic Sensitivity]] or the ability to cast [[rangoric-srd/spells/Magic Overview#Psychic Magic|psychic spells]].

**Benefit**: Choose two [[rangoric-srd/skills/Skills Overview#^occult-unlocks|occult skill unlocks]]. You can use each of them one more time per day (or per week, for automatic writing). You must have at least 1 rank in the skill of each unlock you choose.
