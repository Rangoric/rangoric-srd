# Extra Ranger Trap

You can use ranger traps more often.

**Prerequisites**: [[rangoric-srd/class-options/archetypes/ranger/Trapper (Archetype)#^trapper-trap|Trap]] class feature.

**Benefit**: You can set [[rangoric-srd/class-options/ranger-traps/Ranger Traps|ranger traps]] two additional times per day.
