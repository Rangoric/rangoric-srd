# Fast Empathy

Your empathic attunement to nature connects you swiftly with bestial minds.

**Prerequisites**: [[rangoric-srd/skills/Animal Handling|Animal Handling]] 5 ranks, [[rangoric-srd/classes/Druid#^druid-wild-empathy|wild empathy]] class feature.

**Benefit**: Using wild empathy is a standard action for you.

**Normal**: Using wild empathy takes as long as the [[rangoric-srd/classes/Druid#^druid-wild-empathy|class feature]] says.
