# Craft Necromantic Focus

You can create necromantic focuses.

**Prerequisites**: Caster level 7th, [[rangoric-srd/feats/Craft Wondrous Item|Craft Wondrous Item]], [[rangoric-srd/feats/Shadehand|Shadehand]].

**Benefit**: You can create any [[rangoric-srd/rules/path-of-shades/The Path of Shades#Necromantic Foci|necromantic focus]] whose prerequisites you meet ([[rangoric-srd/rules/path-of-shades/The Path of Shades#Crafting Necromantic Foci|crafting necromantic foci]]).

**Special**: It’s one of the [[rangoric-srd/rules/path-of-shades/The Path of Shades#Shadetouched Feats|shadetouched feats]] of [[rangoric-srd/rules/path-of-shades/The Path of Shades|the Path of Shades]].
