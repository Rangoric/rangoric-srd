# Dimensional Savant

You flash into and out of reality so quickly it is impossible to tell exactly where you are at any given time.

**Prerequisites**: [[rangoric-srd/feats/Dimensional Agility|Dimensional Agility]], [[rangoric-srd/feats/Dimensional Assault|Dimensional Assault]], [[rangoric-srd/feats/Dimensional Dervish|Dimensional Dervish]], ability to use the [[rangoric-srd/classes/Monk#^monk-abundant-step|abundant step]] class feature or cast *[[rangoric-srd/spells/Dimension Door|dimension door]]*, base attack bonus +9.

**Benefit**: While using the [[rangoric-srd/feats/Dimensional Dervish|Dimensional Dervish]] feat, you provide [[rangoric-srd/combat/Combat Modifiers#Flanking|flanking]] from all squares you attack from. Flanking starts from the moment you make an attack until the start of your next turn. You can effectively flank with yourself and with multiple allies when using this feat.
