# Tree Leaper

You use the spring of tree branches to help you leap from tree to tree.

**Benefit**: When you are in a tree, you count as having a running start when you jump.

**Normal**: Jumping needs a running start; see [[rangoric-srd/skills/Athletics|Athletics]].
