# Signature Skill

Your ability with one skill is the stuff of legends, and you can do things with it that others cannot.

**Benefit**: Choose a skill. You get the benefit of [[rangoric-srd/feats/Skill Focus|Skill Focus]] in that skill, and you gain its [[rangoric-srd/skills/Skills Overview#^skill-unlocks|unlocks]] as your ranks reach each tier. If you choose Craft, Profession or Performance, the unlocks apply to one category only, such as Craft (bows).

**Special**: You can take this feat only once. It counts as Skill Focus in the chosen skill for anything that requires Skill Focus, so taking Skill Focus in the same skill adds nothing. It stacks with the [[rangoric-srd/classes/Rogue#^rogue-edge|rogue’s edge]], which must be used on different skills.
