# Armor Proficiency (Heavy)

**Prerequisites**: [[rangoric-srd/feats/Armor Proficiency (Light)|Armor Proficiency (light)]], [[rangoric-srd/feats/Armor Proficiency (Medium)|Armor Proficiency (medium)]].

**Special**: A class whose armor proficiencies include heavy armor gives this feat as a bonus feat, so its characters need not select it; each class says which armor it is proficient with.
