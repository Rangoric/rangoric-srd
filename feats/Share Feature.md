# Share Feature

The animal expands its capabilities and learns one of its master’s class features.

**Prerequisites**: [[rangoric-srd/classes/Druid#^druid-animal-companion|Animal companion]], master must have the chosen class feature.

**Benefit**: Choose one of the following class features: [[rangoric-srd/classes/Fighter#^fighter-bravery|bravery]], [[rangoric-srd/classes/Ranger#^ranger-camouflage|camouflage]], [[rangoric-srd/classes/Ranger#^ranger-favored-terrain|favored terrain]], [[rangoric-srd/classes/Ranger|hide in plain sight]], [[rangoric-srd/classes/Druid#^druid-resist-natures-lure|resist nature’s lure]], [[rangoric-srd/classes/Ranger|track]], [[rangoric-srd/classes/Druid#^druid-trackless-step|trackless step]], [[rangoric-srd/classes/Druid#^druid-venom-immunity|venom immunity]] and [[rangoric-srd/classes/Druid#^druid-woodland-stride|woodland stride]]. The animal companion gains the benefits of the selected class feature, using its Hit Dice as its level in its master’s class for the purpose of this ability, though the animal companion doesn’t count as having the class feature for the purpose of fulfilling prerequisites.
