# Mantis Style

You have learned to target vital areas with crippling accuracy.

**Prerequisites**: [[rangoric-srd/feats/Improved Unarmed Strike|Improved Unarmed Strike]], [[rangoric-srd/feats/Stunning Fist|Stunning Fist]], [[rangoric-srd/skills/Medicine|Medicine]] 3 ranks.

**Benefit**: You gain one more Stunning Fist attempt per day. While using this style, the DCs of effects you deliver with Stunning Fist increase by 2.
