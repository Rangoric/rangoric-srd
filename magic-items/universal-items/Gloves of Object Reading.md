# Gloves of Object Reading

While wearing these gloves, the user can learn the details of an inanimate object’s previous owner if he handles the object, as if manifesting the [[rangoric-srd/powers/Object Reading (Power)|object reading]] power.  
Faint clairsentience; ML 1st; Craft Universal Item, object reading; Price 3,000 gp.
