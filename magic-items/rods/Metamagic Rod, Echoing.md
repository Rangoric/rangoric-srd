# Metamagic Rod, Echoing

The wielder can cast up to three spells per day that can be cast an additional time that day as if using the [[rangoric-srd/feats/Echoing Spell|Echoing Spell]] feat.

Strong (no school); CL 17th; [[rangoric-srd/feats/Craft Rod|Craft Rod]], [[rangoric-srd/feats/Echoing Spell|Echoing Spell]]; Price 14,000 gp (lesser), 54,000 gp (normal), 121,500 gp (greater); Cost 7,000 gp (lesser), 27,000 gp (normal), 60,750 gp (greater).
