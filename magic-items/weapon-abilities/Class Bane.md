# Class Bane

A class bane weapon excels at attacking one character class. Against its designated foe, its effective enhancement bonus is +2 better than its normal enhancement bonus. It deals an extra 2d6 points of damage against the foe. Bows, crossbows, and slings so crafted bestow the bane quality upon their ammunition. To randomly determine a weapon’s designated foe, roll on the following table.

| d% | Designated Foe |
|---|---|
| 01–09 | Barbarian |
| 10–18 | Bard |
| 19–27 | Cleric |
| 28–36 | Druid |
| 37–47 | Fighter |
| 48–56 | Monk |
| 57–65 | Paladin |
| 66–74 | Ranger |
| 75–83 | Rogue |
| 84–91 | Sorcerer |
| 92–100 | Wizard |

Moderate conjuration; CL 9th; [[rangoric-srd/feats/Craft Magic Arms and Armor|Craft Magic Arms and Armor]], *[[rangoric-srd/spells/Summon Monster I|summon monster I]]*; Price +2 bonus.
