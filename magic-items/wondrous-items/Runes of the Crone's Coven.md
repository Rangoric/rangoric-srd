# Runes of the Crone's Coven

This leather pouch contains a set of black stones, each engraved with a different rune of ill fortune. When used as part of [[rangoric-srd/classes/Skald#^skald-spell-kenning|spell kenning]], they allow the user to cast spells from the [[rangoric-srd/spells/Witch Spell List|witch spell list]]. To cast a witch spell, the possessor must spend twice as long casting as for normal spell kenning, and must use a spell slot 1 level higher than normal. If the possessor has the [[rangoric-srd/classes/Skald#^skald-master-skald|master skald]] class feature, determine casting time as though he lacked that class feature instead of doubling casting time. The tiles can be used once per day.

Strong universal; CL 12th; [[rangoric-srd/feats/Craft Wondrous Item|Craft Wondrous Item]], _[[rangoric-srd/spells/Imbue with Spell Ability|imbue with spell ability]]_, creator must be able to cast 6th-level [[rangoric-srd/classes/Witch|witch]] spells; Price 16,000 gp; Cost 8,000 gp; Weight 1 lb.
