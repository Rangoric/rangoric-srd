# Scabbard of Return

This fabulous item is extremely popular with those who wield hurled weapons. A scabbard of return allows the last item sheathed within it to be returned to the hands of its owner upon utterance of a command word. The scabbard functions only with weapons and cannot retrieve an item that is on another plane.

Moderate conjuration; CL 9th; [[rangoric-srd/feats/Craft Wondrous Item|Craft Wondrous Item]], *[[rangoric-srd/spells/Teleport|teleport]]*; Price 4,000 gp; Weight 1 lb.
