# Abundant Step

*A [[rangoric-srd/classes/Unchained Monk#^unchained-monk-ki-powers|ki power]] (Su).*

A monk with this ki power can slip magically between spaces, as if using the spell *[[rangoric-srd/spells/Dimension Door|dimension door]]*. Using this ability is a move action that consumes 2 points from his ki pool. The monk's caster level for this effect is equal to his monk level. He cannot take other creatures with him when he uses this ability. A monk must be at least 8th level before selecting this ki power.
