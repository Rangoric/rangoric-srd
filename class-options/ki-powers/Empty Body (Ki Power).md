# Empty Body

*A [[rangoric-srd/classes/Unchained Monk#^unchained-monk-ki-powers|ki power]] (Su).*

A monk with this ki power gains the ability to assume an ethereal state for 1 minute as though using the spell *[[rangoric-srd/spells/Etherealness|etherealness]]*, using his monk level as his caster level. Using this ability is a move action that consumes 3 points from the monk's ki pool. This ability affects only the monk and cannot be used to make other creatures ethereal.
