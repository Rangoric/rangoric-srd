# Ki Guardian

_A [[rangoric-srd/classes/Unchained Monk#^unchained-monk-ki-powers|ki power]] (Su)._

As an immediate action before a targeted effect that also targets other allies, or an area effect whose area includes other allies, attacks one of his defenses, a monk with this ability can spend any number of ki points and designate a number of adjacent allies equal to the number of ki points spent. The effect attacks the monk once for each designated ally, against his defense instead of the ally's. For each miss, the corresponding ally treats the effect as having missed it, and for each hit, the corresponding ally treats the effect as having hit it. If any of these attacks hits the monk (including the original attack against him), the monk treats the effect as having hit him. A monk must be at least 6th level before selecting this ki power.
