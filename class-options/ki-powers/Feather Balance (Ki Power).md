# Feather Balance

*A [[rangoric-srd/classes/Unchained Monk#^unchained-monk-ki-powers|ki power]] (Ex).*

A monk with this ability can spend 1 ki point as a swift action to achieve perfect balance. While this is active, the monk treats any [[rangoric-srd/skills/Acrobatics|Acrobatics]] attempt made to balance as if he had rolled a 20. This ability lasts for 1 minute.
