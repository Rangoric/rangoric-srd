# Rage Powers

The [[rangoric-srd/classes/Barbarian|barbarian]]’s and the [[rangoric-srd/classes/Skald|skald]]’s rage powers. Each class note says how they’re gained, and the skald’s says which ones it can take and share; each power’s `class` property names the classes that can take it. Each note has a `level` property (the minimum barbarian level, 2 when there is none, by which they’re grouped below), the `book` it comes from, and `stance: true` for stances.
