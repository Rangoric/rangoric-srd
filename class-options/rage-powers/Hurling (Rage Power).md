# Hurling

*A [[rangoric-srd/classes/Barbarian#^barbarian-rage-powers|rage power]] (Ex).*

As lesser hurling, but the barbarian can increase the range increment to 20 feet or increase the size of a hurled object by one size category. A barbarian must have the [[rangoric-srd/class-options/rage-powers/Hurling, Lesser (Rage Power)|lesser hurling]] rage power to select this rage power.

A barbarian must be at least 8th level to select this rage power.
