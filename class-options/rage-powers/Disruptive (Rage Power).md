# Disruptive

*A [[rangoric-srd/classes/Barbarian#^barbarian-rage-powers|rage power]] (Ex).*

When raging, the barbarian gains [[rangoric-srd/feats/Disruptive|Disruptive]] as a bonus feat.

The barbarian must have the [[rangoric-srd/class-options/rage-powers/Superstition (Rage Power)|superstition]] rage power to select this rage power.

A barbarian must be at least 8th level to select this rage power.
