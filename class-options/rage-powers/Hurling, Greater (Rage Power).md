# Hurling, Greater

*A [[rangoric-srd/classes/Barbarian#^barbarian-rage-powers|rage power]] (Ex).*

As hurling, but the barbarian can increase the range increment to 30 feet or increase the size of a hurled object by two size categories.

A barbarian must have the [[rangoric-srd/class-options/rage-powers/Hurling (Rage Power)|hurling]] rage power to select this rage power.

A barbarian must be at least 12th level to select this rage power.
