# Agony

_A [[rangoric-srd/classes/Witch#^witch-major-hex|major hex]] (Su)._

With a quick incantation, a witch can place this hex on one creature within 60 feet, causing them to suffer intense pain. The target is nauseated for a number of rounds equal to the witch's level. It attacks Fortitude, and a miss negates this effect. On a hit, the target can make the hex attack it again each round, and a miss ends the effect. Whether it hits or misses, a creature cannot be the target of this hex again for 1 day.
