# Tongues

*A [[rangoric-srd/classes/Witch#^witch-hex|witch hex]] or [[rangoric-srd/classes/Shaman#^shaman-hex|shaman hex]] (Su).*

A witch or shaman with this hex can understand any spoken language for a number of minutes per day equal to her level, as *[[rangoric-srd/spells/Comprehend Languages|comprehend languages]]*. This duration does not need to be consecutive, but it must be spent in 1-minute increments. At 5th level, she can use this ability to speak any language, as per *[[rangoric-srd/spells/Tongues|tongues]]*.
