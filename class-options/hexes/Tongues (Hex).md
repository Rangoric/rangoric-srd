# Tongues

_A [[rangoric-srd/classes/Witch#^witch-hex|witch hex]] or [[rangoric-srd/classes/Shaman#^shaman-hex|shaman hex]] (Su)._

A witch or shaman with this hex can understand any spoken language for a number of minutes per day equal to her level, as _[[rangoric-srd/spells/Comprehend Languages|comprehend languages]]_. This duration does not need to be consecutive, but it must be spent in 1-minute increments. At 5th level, she can use this ability to speak any language, as per _[[rangoric-srd/spells/Tongues|tongues]]_.
