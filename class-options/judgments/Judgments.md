# Judgments

The judgments an [[rangoric-srd/classes/Inquisitor (Class)|inquisitor]] chooses from when she uses her [[rangoric-srd/classes/Inquisitor (Class)#^inquisitor-judgment|judgment]] class feature, one note each. The class note says how judgment works (a swift action, uses per day, lasting until the combat ends, changing judgments, sacred or profane bonuses, and the second, third and true judgments); each judgment note says only what it grants.
