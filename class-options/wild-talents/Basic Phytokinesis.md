# Basic Phytokinesis

_A [[rangoric-srd/class-options/wild-talents/Wild Talents#Utility Wild Talents|utility wild talent]] of the [[rangoric-srd/classes/Kineticist|kineticist]]._

- **Element**: [[rangoric-srd/class-options/elements/Wood Element|wood]]
- **Type**: utility (Sp)
- **Level**: 1
- **Burn**: 0

You can prune and otherwise tend plants within 30 feet without using gardening tools. You can search wooded areas and other plant-heavy areas from a distance as if using the _[[rangoric-srd/spells/Sift|sift]]_ cantrip. By concentrating, you can detect plants within 120 feet as if using _[[rangoric-srd/spells/Detect Animals or Plants|detect animals or plants]]_.
