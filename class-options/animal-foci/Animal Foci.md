# Animal Foci

The animals a creature can emulate with the [[rangoric-srd/classes/Hunter#^hunter-animal-focus|animal focus]] class feature. The [[rangoric-srd/classes/Hunter|hunter]]’s class note says how animal focus works (how long it lasts, applying it to an animal companion, and taking two at once); each focus note says only what that animal grants. Where a focus improves with level, it uses the hunter’s level, or whatever level the ability that grants animal focus says to use instead.
