# Golem Constructor

*An [[rangoric-srd/classes/Wizard#^wizard-arcane-discoveries|arcane discovery]].*

You have learned the art and craft of creating a single type of golem (such as stone golems or iron golems). When creating a golem of this type, you count as having the [[rangoric-srd/feats/Craft Wondrous Item|Craft Wondrous Item]], [[rangoric-srd/feats/Craft Magic Arms and Armor|Craft Magic Arms and Armor]], and [[rangoric-srd/feats/Craft Construct|Craft Construct]] feats. You must meet all other construction requirements for the golem as normal. You may select this discovery multiple times. Each time you select this discovery, it applies to a different kind of golem. You must be at least a 9th-level wizard to select this discovery.
