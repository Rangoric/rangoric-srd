# Desperate Evasion

*A [[rangoric-srd/class-options/dares/Dares|dare]] (Ex) for gunslingers and swashbucklers.*

While this dare is active, you gain the [[rangoric-srd/classes/Rogue#^rogue-evasion|evasion]] class feature. If you already have this class feature, while this dare is active you roll twice when making a Reflex saving throw and take the higher result. You regain 1 grit or panache point when you succeed at two Reflex saving throws while using this dare.
