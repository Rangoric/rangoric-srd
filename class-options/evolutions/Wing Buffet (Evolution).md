# Wing Buffet

*A 1-point evolution (Ex) for a [[rangoric-srd/classes/Summoner|summoner]]’s eidolon.*

An eidolon learns to use its wings to batter foes, granting it two wing buffet attacks. These attacks are secondary attacks. The wing buffets deal 1d4 points of damage (1d6 if Large, 1d8 if Huge). The eidolon must possess the [[rangoric-srd/class-options/evolutions/Flight (Evolution)|flight]] evolution, with wings, to select this evolution.
