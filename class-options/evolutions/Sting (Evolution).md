# Sting

*A 1-point evolution (Ex) for a [[rangoric-srd/classes/Summoner|summoner]]’s eidolon.*

An eidolon possesses a long, barbed stinger at the end of its tail, granting it a sting attack. This attack is a primary attack. The sting deals 1d4 points of damage (1d6 if Large, 1d8 if Huge). The eidolon must possess the [[rangoric-srd/class-options/evolutions/Tail (Evolution)|tail]] evolution to take this evolution. This evolution can be selected more than once, but the eidolon must possess an equal number of the tail evolution.
