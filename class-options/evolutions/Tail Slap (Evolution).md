# Tail Slap

*A 1-point evolution (Ex) for a [[rangoric-srd/classes/Summoner|summoner]]’s eidolon.*

An eidolon can use its tail to bash nearby foes, granting it a tail slap attack. This attack is a secondary attack. The tail slap deals 1d6 points of damage (1d8 if Large, 2d6 if Huge). The eidolon must possess the [[rangoric-srd/class-options/evolutions/Tail (Evolution)|tail]] evolution to take this evolution. This evolution can be selected more than once, but the eidolon must possess an equal number of the tail evolution.
