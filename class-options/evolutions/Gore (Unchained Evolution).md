# Gore

_A 2-point evolution (Ex) for an [[rangoric-srd/classes/Unchained Summoner|unchained summoner]]’s eidolon._

The eidolon grows a number of horns on its head, giving it a gore attack. This attack is a primary attack. The gore deals 1d6 points of damage (1d8 if Large, 2d6 if Huge). _Requirements_: Agathion, daemon, demon, devil, div, elemental, protean, or psychopomp subtype.
