# Tail

_A 1-point evolution (Ex) for an [[rangoric-srd/classes/Unchained Summoner|unchained summoner]]’s eidolon._

The eidolon grows a long, powerful tail. This grants it a +2 racial bonus on Acrobatics checks to balance on a surface. This evolution can be selected more than once. _Requirements_: Agathion, daemon, demon, devil, div, elemental, protean, or psychopomp subtype.
