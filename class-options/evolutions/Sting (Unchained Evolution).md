# Sting

*A 1-point evolution (Ex) for an [[rangoric-srd/classes/Unchained Summoner|unchained summoner]]’s eidolon.*

The eidolon possesses a long, barbed stinger at the end of its tail, granting it a sting attack. This attack is a primary attack. The sting deals 1d4 points of damage (1d6 if Large, 1d8 if Huge). This evolution can be selected more than once, up to the number of [[rangoric-srd/class-options/evolutions/Tail (Unchained Evolution)|tail]] evolutions the eidolon possesses. *Requirements*: Agathion, daemon, demon, devil, div, elemental, protean, or psychopomp subtype; tail evolution.
