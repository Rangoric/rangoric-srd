# Riding Python

_An [[rangoric-srd/class-options/animal-companions/Animal Companions|animal companion]] that a [[rangoric-srd/classes/Druid#^druid-animal-companion|druid]] can choose in place of a base creature (a riding python)._

- **Size**: Medium
- **Speed**: 30 ft.
- **AC**: +1 natural armor
- **Attack**: bite (1d6)
- **Ability scores**: Str 11, Dex 14, Con 13, Int 1, Wis 10, Cha 4
- **CMD**: can't be tripped
- **Special qualities**: [[rangoric-srd/monsters/abilities/Blindsight|blindsight]] 60 ft.

- **Ability scores**: Str +2, Con +2
- **Special qualities**: combat training (see the [[rangoric-srd/skills/Animal Handling|Animal Handling]] skill)
