# Smoke Bomb

_An [[rangoric-srd/classes/Alchemist#^alchemist-discovery|alchemist discovery]]\*._

When the alchemist creates a bomb, he can choose to have it create a cloud of thick smoke when it detonates. The cloud functions as _[[rangoric-srd/spells/Fog Cloud|fog cloud]]_, filling an area equal to twice the bomb’s splash radius for 1 round per level.
