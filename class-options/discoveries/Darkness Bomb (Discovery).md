# Darkness Bomb

_An [[rangoric-srd/classes/Alchemist#^alchemist-discovery|alchemist discovery]]\*._

When the alchemist creates a bomb, he can choose to have it suppress light sources on the target. This extinguishes nonmagical light sources carried by the target and dispels magical light sources for 1 round/level as _[[rangoric-srd/spells/Deeper Darkness|deeper darkness]]_.
