# Darkness Bomb

*An [[rangoric-srd/classes/Alchemist#^alchemist-discovery|alchemist discovery]]\*.*

When the alchemist creates a bomb, he can choose to have it suppress light sources on the target. This extinguishes nonmagical light sources carried by the target and dispels magical light sources for 1 round/level as *[[rangoric-srd/spells/Deeper Darkness|deeper darkness]]*.
