# Mutagen

*An [[rangoric-srd/classes/Alchemist#^alchemist-discovery|alchemist discovery]] (Su).*

This discovery gives the alchemist the [[rangoric-srd/classes/Alchemist#^alchemist-mutagen|mutagen]] class ability. (This discovery exists so alchemist archetypes who have variant mutagens, such as the mindchemist, can learn how to make standard mutagens.)
