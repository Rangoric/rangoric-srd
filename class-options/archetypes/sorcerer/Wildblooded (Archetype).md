# Wildblooded

_A [[rangoric-srd/classes/Sorcerer#^sorcerer-archetypes|sorcerer]] [[rangoric-srd/class-options/archetypes/Archetypes|archetype]]._

A wildblooded [[rangoric-srd/classes/Sorcerer|sorcerer]] has a mutated version of a more common [[rangoric-srd/class-options/bloodlines/Bloodlines|bloodline]], with one [[rangoric-srd/classes/Sorcerer#^sorcerer-bloodline|arcana]] and at least one [[rangoric-srd/classes/Sorcerer#^sorcerer-bloodline|bloodline power]] that are different from those of an unmutated bloodline. When creating a wildblooded sorcerer, select an existing bloodline, then select one of the following mutated bloodlines associated with that bloodline. Use the normal bloodline's class skill, bonus spells, and bonus feats, and the mutated bloodline's bloodline arcana. Use the normal bloodline's bloodline powers, except when the mutated bloodline replaces one of those powers.
