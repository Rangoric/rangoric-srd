# Inspired Chemist

*An [[rangoric-srd/classes/Alchemist#^alchemist-archetypes|alchemist]] [[rangoric-srd/class-options/archetypes/Archetypes|archetype]].*

Akin to a [[rangoric-srd/class-options/archetypes/alchemist/Mindchemist (Archetype)|mindchemist]], inspired chemists use a type of [[rangoric-srd/class-options/discoveries/Cognatogen (Discovery)|cognatogen]] that, instead of increasing their mental ability scores, grants them an inspiration pool like that of an [[rangoric-srd/classes/Investigator#^investigator-inspiration|investigator]]. This inspiration provides an inspired chemist amazing powers to avoid danger, but takes a toll on both physical power and health.

**Inspiring Cognatogen**: At 1st level, an inspired chemist learns how to create an inspiring cognatogen, as the [[rangoric-srd/class-options/discoveries/Inspiring Cognatogen (Discovery)|inspiring cognatogen]] discovery. This ability replaces the [[rangoric-srd/classes/Alchemist#^alchemist-mutagen|mutagen]] class ability. (This means that an inspired chemist cannot create mutagens unless he selects the [[rangoric-srd/class-options/discoveries/Mutagen (Discovery)|mutagen]] discovery.)

**Bonus Feats**: An inspired chemist can select [[rangoric-srd/feats/Skill Focus|Skill Focus]] ([[rangoric-srd/skills/Engineering|Engineering]], [[rangoric-srd/skills/Imitation|Imitation]], [[rangoric-srd/skills/Medicine|Medicine]], any [[rangoric-srd/skills/Knowledge|Knowledge skill]], [[rangoric-srd/skills/Sense Motive|Sense Motive]], [[rangoric-srd/skills/Arcana|Arcana]], or [[rangoric-srd/skills/Emulation|Emulation]]) in place of a [[rangoric-srd/classes/Alchemist#^alchemist-discovery|discovery]].

**Bonus Investigator Talents**: An inspired chemist can select any two [[rangoric-srd/class-options/investigator-talents/Investigator Talents|investigator talents]] in place of a discovery, but can use these talents only while under the effect of an inspiring cognatogen.

**Languages**: An inspired chemist can learn three languages in place of a discovery.

**Discoveries**: The following [[rangoric-srd/class-options/discoveries/Discoveries|discoveries]] complement the inspired chemist archetype: [[rangoric-srd/class-options/discoveries/Grand Inspiring Cognatogen (Discovery)|grand inspiring cognatogen]], [[rangoric-srd/class-options/discoveries/Greater Inspiring Cognatogen (Discovery)|greater inspiring cognatogen]], and [[rangoric-srd/class-options/discoveries/Inspired Bomb (Discovery)|inspired bomb]].
