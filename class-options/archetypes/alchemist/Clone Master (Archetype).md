# Clone Master

_An [[rangoric-srd/classes/Alchemist#^alchemist-archetypes|alchemist]] [[rangoric-srd/class-options/archetypes/Archetypes|archetype]]._

Clone masters practice duplicating existing creatures in order to better understand how to create new life. A clone master has the following class features.

**Bomb**: A clone master's bombs deal damage one die step lower than normal (regular bombs deal d4s, concussive bombs deal 1d3s, and so on). This otherwise functions as and replaces the standard alchemist [[rangoric-srd/classes/Alchemist#^alchemist-bomb|bomb]] class feature.

**Lesser Simulacrum**: At 7th level, a clone master adds _[[rangoric-srd/spells/Simulacrum, Lesser|lesser simulacrum]]_ to his formula book as a 3rd-level extract.

**Rebirth**: At 8th level, a clone master can prepare a clone of himself that awakens if he is slain. Creating the clone costs 5,000 gp, takes 1 week of work, and requires 3 additional weeks for the clone to grow to maturity. If he dies, the clone awakens as if the alchemist had used the _[[rangoric-srd/spells/Clone|clone]]_ spell on himself. He can have one inert clone of himself at a time. Unused clones created by a clone master do not rot. This ability replaces [[rangoric-srd/classes/Alchemist#^alchemist-poison-resistance|poison resistance]] +6 and poison immunity.

**Simulacrum**: At 13th level, a clone master adds _[[rangoric-srd/spells/Simulacrum|simulacrum]]_ to his formula book as a 5th-level extract.

**Clone**: At 16th level, a clone master adds _[[rangoric-srd/spells/Clone|clone]]_ to his formula book as a 6th-level extract.

**Discoveries**: The following [[rangoric-srd/class-options/discoveries/Discoveries|discoveries]] complement the clone master archetype: [[rangoric-srd/class-options/discoveries/Alchemical Simulacrum (Discovery)|alchemical simulacrum]], [[rangoric-srd/class-options/discoveries/Doppelganger Simulacrum (Discovery)|doppelganger simulacrum]], [[rangoric-srd/class-options/discoveries/Preserve Organs (Discovery)|preserve organs]], and [[rangoric-srd/class-options/discoveries/Parasitic Twin (Discovery)|parasitic twin]].
