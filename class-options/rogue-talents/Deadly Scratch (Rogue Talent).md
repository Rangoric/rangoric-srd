# Deadly Scratch

_A [[rangoric-srd/classes/Rogue#^rogue-talents|rogue talent]] (Ex) that only [[rangoric-srd/races/Catfolk|catfolk]] can take._

A catfolk rogue with this talent can [[rangoric-srd/rules/Afflictions#Applying Poison|apply poison]] to her claws without accidentally poisoning herself. A catfolk rogue must have the [[rangoric-srd/races/racial-traits/Cat's Claws|cat's claws]] racial trait and the poison use class feature (from the [[rangoric-srd/class-options/archetypes/rogue/Poisoner (Archetype)|poisoner]] or [[rangoric-srd/class-options/archetypes/rogue/Spy (Archetype)|spy]]) before taking this talent.
