# Ledge Walker

*A [[rangoric-srd/classes/Rogue#^rogue-talents|rogue talent]] (Ex).*

This ability allows a rogue to move along narrow surfaces at full speed using the Acrobatics skill without penalty. In addition, a rogue with this talent is not [[rangoric-srd/rules/Special Abilities and Conditions#^flat-footed|flat-footed]] when using Acrobatics to move along narrow surfaces.
