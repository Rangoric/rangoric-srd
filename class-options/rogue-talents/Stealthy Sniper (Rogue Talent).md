# Stealthy Sniper

*An [[rangoric-srd/classes/Rogue#^rogue-advanced-talents|advanced talent]] (Ex).*

When a character with this talent uses the Stealth skill to snipe, she only suffers a –10 penalty on the [[rangoric-srd/skills/Stealth|Stealth]] check, instead of –20.
