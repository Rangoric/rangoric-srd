# Certainty

*A [[rangoric-srd/classes/Rogue#^rogue-talents|rogue talent]] (Ex).*

The rogue chooses one of the skills she selected with [[rangoric-srd/classes/Rogue#^rogue-edge|rogue's edge]]. Once per day, the rogue can reroll a skill check she just made with the selected skill and take the better result. She can use this reroll with the selected skill one additional time per day at 10th level and every 5 levels thereafter. A rogue can select this talent multiple times. Each time, the rogue must choose a different skill. A rogue must have the rogue's edge class feature before selecting this talent.
