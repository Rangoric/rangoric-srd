# Vicious Claws

_A [[rangoric-srd/classes/Rogue#^rogue-talents|rogue talent]] (Ex) that only [[rangoric-srd/races/Catfolk|catfolk]] can take._

A catfolk with this talent uses d8s to roll [[rangoric-srd/classes/Rogue#^rogue-sneak-attack|sneak attack]] damage instead of d6s, but only when she uses her claws to make the sneak attack. A catfolk rogue must have the [[rangoric-srd/races/racial-traits/Cat's Claws|cat's claws]] racial trait before taking this talent.
