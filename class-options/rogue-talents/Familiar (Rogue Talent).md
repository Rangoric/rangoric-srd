# Familiar

*An [[rangoric-srd/classes/Rogue#^rogue-advanced-talents|advanced talent]] (Ex).*

A character with this talent gains a familiar as the familiar option of the wizard’s arcane bond class feature. This ability functions exactly like that part of the class feature, but the rogue’s effective wizard level is her rogue level –4. The rogue must have the [[rangoric-srd/class-options/rogue-talents/Minor Magic (Rogue Talent)|minor magic]] and [[rangoric-srd/class-options/rogue-talents/Major Magic (Rogue Talent)|major magic]] talents before she can choose this trick.
