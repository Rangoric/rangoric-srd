# Implement Schools

The implement schools of the [[rangoric-srd/classes/Occultist|occultist]], one note each, each representing a [[rangoric-srd/spells/Schools of Magic|school of magic]]. The class note’s [[rangoric-srd/classes/Occultist#^occultist-implements|Implements]] has the rules: an occultist learns two schools at 1st level and one more at 2nd level and every 4 levels after, can select a school more than once, and uses one of the school’s implements to cast its spells. Each note lists the school’s implements, its resonant power (granted by an implement holding [[rangoric-srd/classes/Occultist#^occultist-mental-focus|mental focus]]), its base focus power and the focus powers it offers.
