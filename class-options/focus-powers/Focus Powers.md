# Focus Powers

The [[rangoric-srd/classes/Occultist|occultist]]’s focus powers, one note each, by [[rangoric-srd/class-options/implement-schools/Implement Schools|implement school]]. The class note’s [[rangoric-srd/classes/Occultist#^occultist-focus-powers|Focus Powers]] has the rules; each school’s base focus power is in its school note, granted with the school. A power is activated by expending [[rangoric-srd/classes/Occultist#^occultist-mental-focus|mental focus]]. Each note has `implement-school` and `level` (the occultist level it can be taken at).
