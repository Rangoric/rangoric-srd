# Rogue and Ninja Advanced Talents

*An [[rangoric-srd/classes/Slayer#^slayer-advanced-talents|advanced talent]] (Ex).*

A slayer can select any of the following advanced ninja or rogue talents in place of an advanced slayer talent: [[rangoric-srd/class-options/rogue-talents/Deadly Sneak (Rogue Talent)|deadly sneak]], [[rangoric-srd/class-options/ninja-tricks/Evasion (Ninja Trick)|evasion]], [[rangoric-srd/class-options/rogue-talents/Hunter's Surprise (Rogue Talent)|hunter's surprise]], [[rangoric-srd/class-options/rogue-talents/Knock-Out Blow (Rogue Talent)|knock-out blow]], [[rangoric-srd/class-options/rogue-talents/Master of Disguise (Rogue Talent)|master of disguise]], [[rangoric-srd/class-options/rogue-talents/Opportunist (Rogue Talent)|opportunist]], and [[rangoric-srd/class-options/rogue-talents/Stealthy Sniper (Rogue Talent)|stealthy sniper]]. A slayer can select this advanced talent multiple times; each time, it grants a new advanced talent from the list.
