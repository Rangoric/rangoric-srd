# Rogue Talent

*A [[rangoric-srd/classes/Slayer#^slayer-talents|slayer talent]] (Ex).*

A slayer can select one of the following rogue talents in place of a slayer talent: [[rangoric-srd/class-options/rogue-talents/Bleeding Attack (Rogue Talent)|bleeding attack]]\*, [[rangoric-srd/class-options/rogue-talents/Camouflage (Rogue Talent)|camouflage]], [[rangoric-srd/class-options/rogue-talents/Combat Trick (Rogue Talent)|combat trick]], [[rangoric-srd/class-options/rogue-talents/Fast Stealth (Rogue Talent)|fast stealth]], [[rangoric-srd/class-options/rogue-talents/Finesse Rogue (Rogue Talent)|finesse rogue]], [[rangoric-srd/class-options/rogue-talents/Firearm Training (Rogue Talent)|firearm training]], [[rangoric-srd/class-options/rogue-talents/Grit (Rogue Talent)|grit]], [[rangoric-srd/class-options/rogue-talents/Hard to Fool (Rogue Talent)|hard to fool]], [[rangoric-srd/class-options/rogue-talents/Lasting Poison (Rogue Talent)|lasting poison]], [[rangoric-srd/class-options/rogue-talents/Powerful Sneak (Rogue Talent)|powerful sneak]], [[rangoric-srd/class-options/rogue-talents/Rogue Crawl (Rogue Talent)|rogue crawl]], [[rangoric-srd/class-options/rogue-talents/Slow Reactions (Rogue Talent)|slow reactions]]\*, [[rangoric-srd/class-options/rogue-talents/Snap Shot (Rogue Talent)|snap shot]], [[rangoric-srd/class-options/rogue-talents/Sniper's Eye (Rogue Talent)|sniper's eye]], [[rangoric-srd/class-options/rogue-talents/Surprise Attack (Rogue Talent)|surprise attack]], [[rangoric-srd/class-options/rogue-talents/Swift Poison (Rogue Talent)|swift poison]], [[rangoric-srd/class-options/rogue-talents/Terrain Mastery (Rogue Talent)|terrain mastery]], [[rangoric-srd/class-options/rogue-talents/Trap Spotter (Rogue Talent)|trap spotter]], [[rangoric-srd/class-options/rogue-talents/Unwitting Ally (Rogue Talent)|unwitting ally]], or [[rangoric-srd/class-options/rogue-talents/Weapon Training (Rogue Talent)|weapon training]]. Any talent effects based on rogue level use the slayer's class level. If the rogue talent has a prerequisite, the slayer must fulfill the prerequisite before taking that rogue talent. This talent can be selected multiple times; each time, it grants the slayer a new rogue talent. Talents marked with an asterisk add effects to sneak attack, and count against the slayer's one such talent per attack.
