# Alchemist Discovery

*An [[rangoric-srd/classes/Investigator#^investigator-investigator-talent|investigator talent]] (Ex).*

The investigator can select one of the following alchemist discoveries as an investigator talent: [[rangoric-srd/class-options/discoveries/Combine Extracts (Discovery)|combine extracts]], [[rangoric-srd/class-options/discoveries/Concentrate Poison (Discovery)|concentrate poison]], [[rangoric-srd/class-options/discoveries/Dilution (Discovery)|dilution]], [[rangoric-srd/class-options/discoveries/Elixir of Life (Discovery)|elixir of life]], [[rangoric-srd/class-options/discoveries/Enhance Potion (Discovery)|enhance potion]], [[rangoric-srd/class-options/discoveries/Eternal Potion (Discovery)|eternal potion]], [[rangoric-srd/class-options/discoveries/Extend Potion (Discovery)|extend potion]], [[rangoric-srd/class-options/discoveries/Infusion (Discovery)|infusion]], [[rangoric-srd/class-options/discoveries/Mutagen (Discovery)|mutagen]], and [[rangoric-srd/class-options/discoveries/Poison Conversion (Discovery)|poison conversion]]. When selecting an alchemist discovery, he must be high enough level to qualify for that discovery, using his investigator level as his [[rangoric-srd/classes/Alchemist|alchemist]] level to determine if he qualifies. This talent can be selected multiple times; each time grants a new alchemist discovery.
