# Rogue Talent

*An [[rangoric-srd/classes/Investigator#^investigator-investigator-talent|investigator talent]] (Ex).*

[[rangoric-srd/class-options/rogue-talents/Terrain Mastery (Rogue Talent)|terrain master]], [[rangoric-srd/class-options/rogue-talents/Trap Spotter (Rogue Talent)|trap spotter]], or [[rangoric-srd/class-options/rogue-talents/Wall Scramble (Rogue Talent)|wall scrambler]]. Any talent effects based on rogue level use the investigator’s class level. If the rogue talent has a prerequisite (such as the major magic rogue talent requiring the minor magic talent), the investigator must fulfill the prerequisite before selecting that rogue talent. This talent can be selected multiple times; each time, it grants the investigator a new rogue talent.
