# Amazing Inspiration

*An [[rangoric-srd/classes/Investigator#^investigator-investigator-talent|investigator talent]] (Ex).*

When using [[rangoric-srd/classes/Investigator#^investigator-inspiration|inspiration]], the investigator rolls a d8 instead of a d6. At 20th level, the investigator rolls 2d8 and adds both dice to the result. An investigator must be at least 7th level to select this talent.
