# Investigator Talents

The [[rangoric-srd/classes/Investigator|investigator]]’s talents, one note each. The class note’s [[rangoric-srd/classes/Investigator#^investigator-investigator-talent|Investigator Talent]] feature has the rules (when they’re gained, and that talents marked \* add to studied combat or studied strike, one per attack). Each note has `studied` (marked \*), `level` (the minimum investigator level, where the talent names one; the list below is grouped by it) and `book`. Two talents open other classes’ options: [[rangoric-srd/class-options/investigator-talents/Alchemist Discovery (Investigator Talent)|alchemist discovery]] (ten [[rangoric-srd/class-options/discoveries/Discoveries|alchemist discoveries]]) and [[rangoric-srd/class-options/investigator-talents/Rogue Talent (Investigator Talent)|rogue talent]] (the listed [[rangoric-srd/class-options/rogue-talents/Rogue Talents|rogue talents]], which keep their rogue notes).
