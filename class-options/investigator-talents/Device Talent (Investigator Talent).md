# Device Talent

*An [[rangoric-srd/classes/Investigator#^investigator-investigator-talent|investigator talent]] (Ex).*

The investigator can use the [[rangoric-srd/skills/Emulation|Emulation]] skill even if not trained in that skill. If the investigator is trained in Emulation, he can use the inspiration ability with that skill without expending uses of inspiration.
