# Invisibility

*A [[rangoric-srd/classes/Oracle#^oracle-revelation|revelation]] (Su) of the [[rangoric-srd/class-options/mysteries/Wind Mystery|wind]] mystery.*

As a standard action, you can become invisible (as per the *[[rangoric-srd/spells/Invisibility|invisibility]]* spell). You can remain invisible for 1 minute per day per oracle level. This duration does not need to be consecutive, but it must be spent in 1-minute increments. Starting at 9th level, each time you activate this ability you can treat it as *[[rangoric-srd/spells/Invisibility, Greater|greater invisibility]]*, though each round spent this way counts as 1 minute of your normal*[[rangoric-srd/spells/Invisibility|invisibility]]* duration. You must be at least 3rd level to select this revelation.
