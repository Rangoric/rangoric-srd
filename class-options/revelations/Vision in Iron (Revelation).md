# Vision in Iron

_A [[rangoric-srd/classes/Oracle#^oracle-revelation|revelation]] (Sp) of the [[rangoric-srd/class-options/mysteries/Metal Mystery|metal]] mystery._

You can use any piece of polished metal at least the size of a dagger as a scrying device, as if using the spell _[[rangoric-srd/spells/Scrying|scrying]]_. At 15th level, this functions like _[[rangoric-srd/spells/Scrying, Greater|greater scrying]]_. You can scry for a number of rounds per day equal to your oracle level; these rounds do not need to be consecutive. You must be at least 7th level to select this revelation.
