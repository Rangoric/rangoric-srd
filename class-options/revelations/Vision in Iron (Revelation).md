# Vision in Iron

*A [[rangoric-srd/classes/Oracle#^oracle-revelation|revelation]] (Sp) of the [[rangoric-srd/class-options/mysteries/Metal Mystery|metal]] mystery.*

You can use any piece of polished metal at least the size of a dagger as a scrying device, as if using the spell *[[rangoric-srd/spells/Scrying|scrying]]*. At 15th level, this functions like *[[rangoric-srd/spells/Scrying, Greater|greater scrying]]*. You can scry for a number of rounds per day equal to your oracle level; these rounds do not need to be consecutive. You must be at least 7th level to select this revelation.
