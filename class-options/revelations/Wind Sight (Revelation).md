# Wind Sight

*A [[rangoric-srd/classes/Oracle#^oracle-revelation|revelation]] (Ex) of the [[rangoric-srd/class-options/mysteries/Wind Mystery|wind]] mystery.*

You ignore penalties on Perception checks based on wind and the first 100 feet of distance. At 7th level, as a standard action, you can see and hear into any area (as if using *[[rangoric-srd/spells/Clairaudience-Clairvoyance|clairaudience]]* and *[[rangoric-srd/spells/Clairaudience-Clairvoyance|clairvoyance]]*) within range as long as there is an unobstructed path for air to travel between you and the target area (this does not require line of effect, meaning the path can turn corners and go through spaces no smaller than 1 inch in diameter). You can use this ability a number of rounds per day equal to your oracle level, but these rounds do not need to be consecutive.

*The shaman has a hex of the same name: [[rangoric-srd/class-options/hexes/Wind Sight (Hex)|wind sight]].*
