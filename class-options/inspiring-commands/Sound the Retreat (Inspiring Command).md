# Sound the Retreat

*A [[rangoric-srd/prestige-classes/Battle Herald#^battle-herald-inspiring-command|battle herald inspiring command]] (Ex).*

Allies gain the benefit of the [[rangoric-srd/feats/Lightning Stance|Lightning Stance]] feat. The battle herald must have the [[rangoric-srd/class-options/inspiring-commands/Scatter (Inspiring Command)|scatter]] ability to select this ability.
