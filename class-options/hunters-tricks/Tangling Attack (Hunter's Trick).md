# Tangling Attack

_A [[rangoric-srd/class-options/hunters-tricks/Hunter's Tricks|hunter’s trick]] (Ex), which a [[rangoric-srd/class-options/archetypes/ranger/Skirmisher (Archetype)|skirmisher]] ranger learns._

The ranger can use this attack as a free action when he makes an attack. If the attack hits, the target is [[rangoric-srd/rules/Special Abilities and Conditions#^entangled|entangled]] for 1 round.
