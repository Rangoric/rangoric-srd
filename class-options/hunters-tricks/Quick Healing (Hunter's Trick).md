# Quick Healing

*A [[rangoric-srd/class-options/hunters-tricks/Hunter's Tricks|hunter’s trick]] (Ex), which a [[rangoric-srd/class-options/archetypes/ranger/Skirmisher (Archetype)|skirmisher]] ranger learns.*

As a swift action, the ranger can make a [[rangoric-srd/skills/Medicine|Medicine]] check to administer first aid on an adjacent dying character. Alternatively, the ranger can administer a potion to an unconscious character as a move action.
