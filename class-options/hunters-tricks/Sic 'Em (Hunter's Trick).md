# Sic 'Em

_A [[rangoric-srd/class-options/hunters-tricks/Hunter's Tricks|hunter’s trick]] (Ex), which a [[rangoric-srd/class-options/archetypes/ranger/Skirmisher (Archetype)|skirmisher]] ranger learns._

The ranger can use this trick as a swift action. His [[rangoric-srd/classes/Ranger#^ranger-animal-companion|animal companion]] makes one melee attack against an adjacent creature. The animal companion must be able to see and hear the ranger to make this attack.
