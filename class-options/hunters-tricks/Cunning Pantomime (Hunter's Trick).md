# Cunning Pantomime

_A [[rangoric-srd/class-options/hunters-tricks/Hunter's Tricks|hunter’s trick]] (Ex), which a [[rangoric-srd/class-options/archetypes/ranger/Skirmisher (Archetype)|skirmisher]] ranger learns._

As a standard action, the ranger can communicate with a single creature as if using the _[[rangoric-srd/spells/Tongues|tongues]]_ spell for 10 minutes. Because the communication is slow and lacks subtlety, the ranger suffers a –4 penalty on all [[rangoric-srd/skills/Deception|Deception]] and [[rangoric-srd/skills/Persuasion|Persuasion]] checks relating to the creature he is communicating with when using this trick.
