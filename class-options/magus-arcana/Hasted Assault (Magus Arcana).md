# Hasted Assault

*A [[rangoric-srd/classes/Magus#^magus-magus-arcana|magus arcana]] (Su).*

The magus can expend 1 point from his arcane pool as a swift action to move more quickly. This functions as *[[rangoric-srd/spells/Haste|haste]]*, but only targets the magus and lasts for a number of rounds equal to the magus’s Intelligence bonus. The magus must be at least 9th level before selecting this magus arcana.
