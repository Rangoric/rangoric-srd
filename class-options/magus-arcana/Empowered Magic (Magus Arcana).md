# Empowered Magic

_A [[rangoric-srd/classes/Magus#^magus-magus-arcana|magus arcana]] (Su)._

The magus can cast one spell per day as if it were modified by the [[rangoric-srd/feats/Empower Spell|Empower Spell]] feat. This does not increase the casting time or the level of the spell. The magus must be at least 6th level before selecting this magus arcana.
