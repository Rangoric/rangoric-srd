# Magus Arcana

The arcana a [[rangoric-srd/classes/Magus|magus]] chooses from, one note each. The class note’s [[rangoric-srd/classes/Magus#^magus-magus-arcana|Magus Arcana]] feature has the rules (when he gains them, choosing one only once unless it says otherwise, and that arcana affecting spells work only on magus spells unless they say otherwise); each note says what it does and any level it requires.
