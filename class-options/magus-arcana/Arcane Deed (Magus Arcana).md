# Arcane Deed

*A [[rangoric-srd/classes/Magus#^magus-magus-arcana|magus arcana]] (Ex).*

When a magus takes this arcana, he can pick any one [[rangoric-srd/class-options/deeds/Deeds|deed]] from the [[rangoric-srd/classes/Swashbuckler#^swashbuckler-deeds|swashbuckler]] class feature as long as that deed can be used by a swashbuckler of his magus level. The magus can use that deed by using points from his arcane pool as the [[rangoric-srd/classes/Swashbuckler#^swashbuckler-panache|panache points]] required for that deed. A magus can take this arcana multiple times, each time gaining a new deed. The magus must have the [[rangoric-srd/class-options/magus-arcana/Flamboyant Arcana (Magus Arcana)|flamboyant arcana]] to select this arcana.
