# Silent Magic

*A [[rangoric-srd/classes/Magus#^magus-magus-arcana|magus arcana]] (Su).*

The magus can cast one spell per day as if it were modified by the [[rangoric-srd/feats/Silent Spell|Silent Spell]] feat. This does not increase the casting time or the level of the spell.
