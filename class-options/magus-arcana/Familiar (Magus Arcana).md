# Familiar

*A [[rangoric-srd/classes/Magus#^magus-magus-arcana|magus arcana]] (Ex).*

The magus gains a familiar, using his magus level as his effective wizard level. This familiar follows the rules for familiars presented in the [[rangoric-srd/classes/Wizard#^wizard-arcane-bond|arcane bond]] wizard class feature.
