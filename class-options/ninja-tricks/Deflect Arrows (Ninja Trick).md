# Deflect Arrows

*A [[rangoric-srd/classes/Ninja#^ninja-tricks|ninja trick]].*

A ninja who selects this ninja trick gains the [[rangoric-srd/feats/Deflect Arrows|Deflect Arrows]] feat as a bonus feat. The ninja must have the [[rangoric-srd/feats/Improved Unarmed Strike|Improved Unarmed Strike]] combat feat before taking this trick.
