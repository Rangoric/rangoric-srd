# Advanced Talents

*A [[rangoric-srd/classes/Ninja#^ninja-master-tricks|master trick]].*

The ninja can select a rogue talent from the list of [[rangoric-srd/class-options/rogue-talents/Rogue Talents#Advanced talents|advanced talents]] in place of a ninja trick. The ninja cannot select a rogue talent that has the same name as a ninja trick. The ninja cannot select [[rangoric-srd/class-options/rogue-talents/Improved Evasion (Rogue Talent)|improved evasion]] unless she has evasion (either as a class feature or as the [[rangoric-srd/class-options/ninja-tricks/Evasion (Ninja Trick)|evasion]] master trick).
