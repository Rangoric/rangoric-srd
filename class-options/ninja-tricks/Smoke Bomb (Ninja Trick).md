# Smoke Bomb

*A [[rangoric-srd/classes/Ninja#^ninja-tricks|ninja trick]] (Ex).*

This ability allows a ninja to throw a smoke bomb that creates a cloud of smoke with a 15-foot radius. This acts like the smoke from a [[rangoric-srd/equipment/Equipment Goods and Services|smokestick]]. The ninja can center this smoke on herself, or throw the bomb as a ranged touch attack with a range of 20 feet. Using this ability is a standard action. Each use of this ability uses up 1 ki point.
