# Class Options Note Rules

What the notes in `class-options` look like. The whole-SRD rules are in the [README](../README.md#note-rules); Sweep and the "Check notes" workflow check both.

## class-option

| Key           | Required | Values          |
| ------------- | -------- | --------------- |
| `srd-type`    | yes      | `class-option`  |
| `section`     | yes      | `Class Options` |
| `option-type` | yes      | `text`          |
| `class`       | yes      |                 |
| `level`       | no       | `number`        |
| `replaces`    | no       | list of `text`  |

Headings, in order:

1. `# (name)`

## overview

| Key        | Required | Values          |
| ---------- | -------- | --------------- |
| `srd-type` | yes      | `overview`      |
